# MND-Hotel
适配DoL 0.5.11.9 
前置：秋枫白桦框架
前言：-代码由AI操刀，我只是调教ai的。我虽然测试过，但对ai不报希望，最好是存档一次再添加mod


MOD介绍：位于康努达塔斯街的仲夏夜之梦，营业时间为每晚的22点至凌晨8点，可以找NPC奈奈对话开个房间，进入房间之后即可邀请认定为恋人的命名npc进行多人or单人强制遭遇战

可以邀请：罗宾、惠特尼、伊甸、凯拉尔、艾弗里、艾利克斯、悉尼。
目前最多邀请3个人（识别游戏内态度的3个恋人槽，在态度里面换恋人，对我来说3个差不多了emm ）
巨鹰、黑狼因为游戏本体也没有兽+人的车轮战可能不好做于是先放着了

流程：进入酒店对话开房→邀请恋人→邀请后再点击一次上床or浴室即可触发遭遇战→可以选择再来一次or结束，结束则是强行推进到第二天早上8点要求退房。

由于悉尼的特殊机制，第一次邀请悉尼会直接触发移除肛板，如果你的存档里悉尼剧情还未触发移除时会导致报错，所以我索性改成强行触发移除了，某种意义上说推进了悉尼剧情？？？



剧情没写多少，主要是为了开音趴。豪华客房和普通客房剧情只有细微文本差异，只是豪华客房增加了象牙怨灵触发口

-  NPC「奈奈」；
- 好感≥81时房费减 £4000
